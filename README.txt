DAYMARK — DAILY LEARNING PLANNER

What's included
- index.html: the app
- manifest.json: installable-app metadata
- sw.js: offline app-shell caching

How to use
1. Upload the contents of this folder to a static HTTPS host (for example, a GitHub Pages site).
2. Open the hosted HTTPS address in Chrome on your Android phone.
3. Use Chrome's menu > Add to Home screen (or Install app, if shown).
4. Add activities, select dates, and tick them off.

Local storage
- Activities are stored in IndexedDB in the browser on this device.
- No account or app server/database is used.
- Use Export backup regularly. Import backup restores tasks.
- Browser data clearing, private/incognito browsing, or changing browser/device can make local records unavailable. Keep backups.

Note
This is a first version. Data does not automatically sync between devices.
